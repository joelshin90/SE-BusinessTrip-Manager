# SE Trip Manager v1.9 — 지도 아이콘·귀국 애니메이션·직원 순서 UI 개선

## 변경사항
- 지도 내 기준 근무지 아이콘: 집 🏠 → 회사 🏢
- 출장지 근무 네임택: 방진복·후드·마스크 착용 직원을 표현한 SVG 아이콘으로 표시
- 온라인 지도 / 간략 지도 양쪽 모두 동일한 아이콘 체계를 적용
- 귀국일 애니메이션 종료 프레임 보장: 재생 속도가 빠르거나 조회 마지막 날이 귀국일인 경우에도 귀국 위치에 정착
- 같은 날짜에 겹치는 출장 일정에서 당일 종료 일정의 귀국 동작을 우선 표시
- 직원 관리 표: 왼쪽 '순서' 열 제거, 맨 오른쪽 단일 열에 '번호 ☰'를 가로 정렬

## 배포
1. 데이터 관리에서 JSON 백업을 다운로드합니다.
2. GitHub Pages 저장소 루트의 `index.html`과 `trip-flight-map.js`를 **함께** 교체합니다.
3. 필요하면 `README.md`도 교체합니다.
4. Commit 후 GitHub Pages를 강력 새로고침합니다.
5. Firebase DB `se-trip-manager/v1`은 유지하며, 초기 업로드를 다시 실행하지 않습니다.

## 검증 범위
- JS 문법 검사 통과
- Chromium 간략 지도 데모: 출발 전/비행/현지 근무/귀국/귀국 완료(종료일과 다음 날) 확인
- 직원 번호와 이동 핸들이 마지막 열에 가로로 배치되는 것 확인
- 외부 지도 타일과 실제 Firebase에 연결한 종단 간 테스트는 미실시

참고: 이동 시간과 경로는 출장 시작일·종료일 기반의 시뮬레이션이며 실제 항공편 정보가 아닙니다.
